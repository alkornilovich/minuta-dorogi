# Сколько стоит минута дороги до работы в Москве

Интерактивная карта к проекту по курсу «Анализ экономических данных» (МФТИ и Сколково, 2026).

Сайт: https://alkornilovich.github.io/minuta-dorogi/

Город разбит на 4 039 шестиугольных ячеек. Для каждой посчитано время на общественном транспорте до работы, цена метра (по объявлениям или по модели) и похожие районы, где метр дешевле. Можно указать адрес своей работы, подобрать район под бюджет и оценить квартиру.

Главный результат: рынок снимает с цены квартиры около 146 тыс. ₽ за каждую минуту дороги до работы, а сама минута по теории Алонсо — Мута — Миллса стоит 9–30 тыс. ₽.

Датасет: [data/moscow_housing_accessibility.csv](data/moscow_housing_accessibility.csv) — 5 371 объявление, 45 признаков; описание полей в [data/dataset_dictionary.csv](data/dataset_dictionary.csv).
